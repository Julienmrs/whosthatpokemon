Mini jeu en **Three.js + TypeScript où le joueur doit reconnaître des Pokémon 3D.

---

##  Lancer le projet

### Prérequis

- Node.js (https://nodejs.org)
- npm (installé avec Node)

Vérifier l’installation :

```bash
node -v
npm -v
```
Dans le dossier du projet :
```bash
npm install
```

Lancer une première fois:
```bash
npm run build; npm run dev
```

Lancer ensuite:
```bash
npm run dev
```
